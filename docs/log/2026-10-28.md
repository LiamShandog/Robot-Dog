# 2026-10-28 · A/B · Project setup and first actuator sizing
Time spent: 2h

## Goal for this session
Set up the repo and documentation system, then size the knee actuator well enough to start choosing a motor.

## What I did
- Wrote the project README (plan, timeline, gates, documentation system) and pushed it.
- Created the repo structure, sub-project READMEs, doc templates and `CLAUDE.md`.
- Learned the actuator architecture: bought outrunner BLDC motor inside my own actuator (planetary gearbox, encoder, housing). Quasi-direct-drive keeps the gear ratio low so the joint stays backdrivable; reflected inertia grows with N².
- Decided to start printing in PLA (it's what I have), treating PLA parts as prototypes.
- Hand-sized the knee for a 7 kg robot with 0.2 m links:
  - Standing: 17.2 N per foot, knee moment arm ≈ 0.143 m, knee torque ≈ 2.4 Nm. Hip torque ≈ 0 because the foot force passes through the hip.
  - Trot peak (2 feet, 3× load): knee torque ≈ 14.4 Nm.
- Converted to motor requirements with Kt ≈ 8.27 / Kv and I = τ / Kt, and checked speed with v = ω × r.
- Chose 8:1 gearing with a ~100 Kv motor: [decision 0003](../decisions/0003-gear-ratio-and-sizing.md).

## What broke / surprised me
- The trot estimate (14.4 Nm) is above the original 12 Nm peak target in the plan. Updated the README target.
- The 6:1, 100 Kv setup has ~3-4× more foot speed than a 0.5 m/s trot needs, so some of that speed can be traded for torque with a higher ratio.
- For motors of the same size, Kv doesn't change torque capability or heat (I²R stays the same); it only trades current against voltage and speed.
- 8:1 makes the sun gear smaller, and it carries full motor torque. That's a risk in PLA.

## What I learned
Choosing a BLDC motor comes down to torque needs, and torque heavily relies on the geometry of your actuation. Also, BLDC motors are measured in Kv, and you can find the current they require by analyze the torque they must provide.

## Data

| | 6:1 | 8:1 (chosen) |
|---|---|---|
| Knee torque, trot peak | 14.4 Nm | 14.4 Nm |
| Motor torque needed | 2.7 Nm | 2.0 Nm |
| Phase current at 100 Kv | ~33 A | ~24 A |
| Usable joint speed | ~21 rad/s | ~16 rad/s |
| Foot speed (hip / knee) | 5.9 / 4.2 m/s | 4.4 / 3.1 m/s |
